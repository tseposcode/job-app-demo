# Job Auto (test version)

A browser-only test version of Job Auto: a job app for graduate and entry-level jobs in South Africa that applies for you.

Open `index.html` (or the GitHub Pages link). Everything is saved in the browser on that device; nothing is sent anywhere.

## Try it

- **Test account:** `thabang@test.com` / `jameson` (set up on every device)
- **Admin PIN:** `2468` (change it on the admin page)

## What works

- Sign up, log in and log out
- Profile with CV upload (PDF or Word, kept on the device), education, skills and job preferences
- 20 sample jobs with search, filters, sorting and a match score that explains itself
- Auto-apply: automatic (applies to strong matches by itself) or one-tap, with a minimum match and a pause switch
- Applied page: statuses move on their own (Sent, Viewed, then Interview or Not successful), with a badge for news
- Admin (behind the PIN): add, edit and delete jobs, see all applications, change the PIN, reset test data

All jobs and companies are made up. The test password is for the demo only.
